# MG Landing Page Clone

## Overview

This project is a front-end clone of the MG (Morris Garages) landing page. It was built to practice responsive web design, layout structuring, and modern front-end development techniques using HTML, CSS, and JavaScript.

## Features

* Responsive landing page
* Clean and modern user interface
* Responsive navigation bar
* Hero section
* Interactive elements using JavaScript
* Mobile-friendly layout
* Cross-browser compatibility

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Project Structure

```text
MG-Landing-Page-Clone/
│
├── index.html
├── style.css
├── script.js
├── images/
└── assets/
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/mg-landing-page-clone.git
```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.

## Purpose

The purpose of this project is to improve front-end development skills by recreating the landing page of the MG website. It focuses on writing clean, organized, and responsive code while following modern web development practices.
